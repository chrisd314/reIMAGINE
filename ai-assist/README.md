# ai-assist

Everything about the AI coding assistant that helped build this project, kept apart from the code, the analysis and the
website.

| File | What it is |
| --- | --- |
| `DECISIONS.md` | Every judgement call made while building the pipeline and the website, one line each, with its reason. Open decisions for the authors are at the top (N1–N4). |
| `PROGRESS.md` | Status notes: what was asked, what was done and checked, what is left, and how to resume. |
| `AI_METHODS.md` | The AI-use log the course asks for: where a model touched the results and how each use was checked. |

The local settings of the assistant (`.claude/`) are git-ignored and stay where the tool expects them.
