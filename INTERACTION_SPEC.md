# Interaction specification

This file is the design contract for the eight scenes required by brief v1.1 §14. Every animated state change maps to a precomputed analysis output. Animation only changes how records are *arranged* or *coloured*. It never creates intermediate findings: numbers crossfade, and they are never tweened through invented values.

**Global conventions**

* **Motion timing.** Control feedback takes 180 ms. Layout and reveal transitions take 700 ms with a cubic in-out easing. Transitions can be interrupted: a new state cancels the running tween and starts from the current drawn positions. The same state always draws the same frame.
* **Reduced motion.** `prefers-reduced-motion` is honoured, and there is a visible **Motion on/off** toggle in the header (stored per viewer). With motion off, every transition becomes an immediate state change or a 150 ms fade. Decorative motion pauses when it is offscreen.
* **Selection.** The selected tale has a dark ring and an amber halo. A pinned pair is drawn as a pair of rings joined by an amber line. Bright emphasis is used only for the current selection or comparison.
* **Colour.** Known labels (ATU chapter, broad region) use the "atlas" palette with filled circles. Discovered communities use a separate "ink" palette and carry a "discovered by Louvain" legend title. Every legend lists names and counts, so colour is never the only cue.
* **State and recovery.** All state is in the URL hash. A **Reset view** control is always visible. Escape clears the current selection.
* **Accessibility.** The network has a synchronised list/table view. Every canvas has an equivalent HTML list. Focus outlines are visible, and all controls are native buttons or inputs.

**Uninterrupted journey (acceptance test).** Open the introduction → reveal the pair → switch Places → Network layout → select a tale → switch representation → recolour → change density → open the pair reader and click a passage → copy the view link → reset. The journey is repeated with the keyboard only, at a 390 px viewport, and with reduced motion. See `tests/browser/` and the verification notes in `STATUS.md`.

## Implementation status (2026-10-30)

All eight scenes are implemented in the Story and Explore views, and the uninterrupted journey passes on desktop, at 390 px, keyboard-only, and with reduced motion (`tests/browser/journey.py`).

* **Story canvases.** These use a *gentle* zoom mode: the page keeps scrolling, Ctrl + wheel or the ＋/－ buttons zoom, and touch does not pan. Explore uses full pan and zoom.
* **Not built.** Node dragging (optional in the brief) and an SVG figure export; Explore downloads PNG instead.
